# AYLUL canonical appearance

Mohammed approved [idle](states/v1/idle.png), [listening](states/v1/listening.png)
and [blocked](states/v1/blocked.png) on 2026-10-11 after the live size/background
preview. [Manifest](states/v1/manifest.json) pins exact source hashes and scope.
These files are the chosen appearance; do not redraw them when preparing other
expressions. Preserve the original evidence versions and source reference board.

Appearance approval accepts the shown state-lighting variation. It does not close
native motion, asset distribution/installer or runtime event acceptance. A listening
image requires actual capture; a success image requires an observed successful
outcome. Preview clicks are synthetic and do not authorize project work.

Happy, speaking, thinking, working, success and sleeping are prepared in the
[candidate pack](candidates/2026-10-11/manifest.json) from the approved idle master;
their generated results require visual review before
joining this approved pack. Candidate generation/alpha cleanup remains reproducible
in dated evidence. Only source assets live here; client packaging waits for its
actual renderer journey, without scaffolding a second asset framework.

The [idle animation v1 pack](animations/v1/idle/README.md) is a separate,
local-preview-only development slice derived from the canonical idle image. It
contains fixed-canvas numbered transparent PNG frames, a byte-identical still,
metadata, and a dependency-free browser preview. Only idle is animated. The three
canonical images and six candidate images remain unchanged; other animations,
runtime event binding, renderer integration, and native performance acceptance are
still pending their owning gates.
